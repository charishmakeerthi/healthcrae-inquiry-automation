# AI-Powered Healthcare Inquiry Management & Triage System

## Project Overview
An AI-powered healthcare inquiry automation system designed to simplify patient enquiry management for healthcare organizations. It helps classify patient enquiries, detect urgency, generate relevant responses, and manage follow-ups through a centralized dashboard.

## Key Features
- Automated patient inquiry classification
- AI-based urgency detection
- Automated response generation
- Centralized admin dashboard
- Patient inquiry tracking and management
- Follow-up workflow automation
- Database integration

## Technology Stack
- Python
- Streamlit
- Google Gemini API
- SQLite
- Pandas
- n8n
- Git and GitHub

## Project Workflow
1. Patient submits an enquiry.
2. AI analyses and classifies the enquiry.
3. Urgency is identified.
4. Enquiry information is stored in the database.
5. Admin manages enquiries through the dashboard.
6. Follow-ups are tracked and managed.

## Project Structure
The repository currently contains the project ZIP file. The extracted source code and documentation can be added as individual files in future commits.

## Installation
Extract the project ZIP file and install dependencies using:

```bash
pip install -r requirements.txt
```

Run the application using:

```bash
streamlit run app.py
```

## Project Objective
To improve healthcare enquiry management through AI-assisted classification, response generation, and workflow automation.
